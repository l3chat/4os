# Поиск и проверка конкурсов

Здесь хранится результат исследования, независимо от внешнего вида сайта. Изменение таблиц, порядка сортировки или оформления карточек не требует повторного поиска.

## Два независимых этапа

1. **Исследование с доступом к интернету.** Найти конкурс, проверить официальные правила нужного сезона, сохранить факты и источники в `<язык>/catalogue.json`. Незаконченные направления поиска записать в `<язык>/backlog.json`. Сейчас подготовлены `en` и `uk`.
2. **Представление без доступа к интернету.** Скрипт `../scripts/render_catalogue.py` проверяет сохранённые данные и создаёт Markdown и JSON для скачивания. Он не ищет сведения и не подменяет неизвестные значения догадками.

Команды из корня репозитория:

```bash
python3 literary-competitions/scripts/render_catalogue.py
python3 literary-competitions/scripts/render_catalogue.py --check
```

Первая команда автоматически обнаруживает `research/*/catalogue.json` и обновляет `docs/contests/<язык>/catalogue.md` и `docs/data/<язык>-catalogue.json`. Вторая проверяет данные и отсутствие расхождений между источником и производными файлами. GitHub Actions запускает вторую команду перед сборкой сайта. Для одного каталога добавить `--language uk` (параметр можно повторять).

Результаты исследования и представление можно обновлять отдельными коммитами. Ветки с незавершёнными исследованиями не обязаны содержать новую вёрстку; перед объединением в `main` производные файлы должны быть обновлены первой командой. Другой формат — CSV, PDF, календарь или иная веб-страница — может использовать те же данные.

## Что записываем

| Поле | Значение |
| --- | --- |
| `id` | Стабильный идентификатор конкурса/категории и сезона; при сортировке не меняется |
| `organizer`, `organizer_country` | Организатор и его страна; это не ограничение для авторов |
| `submission_languages` | Принимаемые языки произведений; не язык описания |
| `submission_type` | Необязательное пояснение: рукопись, опубликованная книга, номинация издателя и т. п. |
| `recurrence` | Число раундов в год, текстовое пояснение, степень подтверждения и источники |
| `next_deadline` | Ближайшая подтверждённая дата, местное время, часовой пояс, оговорки и источники |
| `opening_date` | Дата будущего открытия, если она объявлена |
| `last_announced_deadline` | Прошедший срок; не показывается как ближайший |
| `entry_fee` | Сумма, ISO-код валюты, единица оплаты, скидки, пакеты, применимый сезон и источники |
| `top_prize` | Денежная часть главного приза, валюта, дополнительные условия и применимый сезон |
| `eligibility` | Географические и другие существенные ограничения |
| `checked_on`, `as_of` | Дата проверки записи и дата всего среза |
| `sources` | Реестр официальных URL с датами и способом доступа |

Значение `null` означает отсутствие подтверждения, а сумма `0` — подтверждённое бесплатное участие. Не заменять одно другим.

На уровне каталога `submission_language` задаёт язык произведений и совпадает с именем папки; `description_language` задаёт язык описания. `catalogue_title` и `coverage.geography_description` позволяют подписать раздел без изменения генератора. Необязательный `entry_fee.is_minimum` отличает минимальный обязательный платёж от фиксированной цены. `top_prize.non_cash_summary` описывает публикацию или другую неденежную награду без выдуманной денежной оценки.

## Правила проверки

- Текущие правила конкретного сезона важнее старых обзоров, архивов и даже устаревших страниц того же организатора.
- `next_deadline.date` заполняется только для подтверждённой будущей даты или даты текущего дня. Прошедший срок переносится в `last_announced_deadline`.
- Если известен только обычный ежегодный день закрытия, но текущая датированная форма его не показывает, сохранять пояснение и оставлять подтверждённую дату пустой. Пример первой партии — Rattle Chapbook Prize. Исключение: действующие постоянные правила прямо задают ежегодный период приёма; в этом случае указать `next_deadline.basis: standing_calendar` и оговорку, что отдельное сезонное объявление не найдено. Генератор явно помечает такую дату в краткой строке.
- Не считать «ежегодно» гарантией будущей даты или неизменности тарифов. Вывод по истории сезонов отмечается `inferred_from_editions`; отсутствие подтверждения — `unknown`.
- Не додумывать часовой пояс, время закрытия, стоимость и призы. Фразу `midnight` без дополнительных уточнений сохранять вместе с оговоркой, а не безусловно сдвигать на сутки.
- Валюты не конвертировать при поиске: пересчёт — отдельная операция с отдельной датой курса.
- Отличать приз одного победителя от общего фонда, компенсацию поездки от свободной денежной суммы, конкурсный взнос от необязательной рецензии, подписки и почтовых расходов.
- Для каждого из четырёх основных полей — частота, срок, взнос, приз — сохранять `source_ids`. Противоречия записывать в примечания.
- `page` означает чтение текста страницы; `indexed_primary_page` — доступ к индексированному тексту официальной страницы. Второй способ не подтверждает работоспособность формы оплаты; это видно в карточке и требует перепроверки перед подачей.
- Статус `open` означает, что приём объявлен открытым на дату проверки. Генерация страницы через месяц не является новой проверкой.

## Охват исследования

Первая английская партия содержала 22 записи из 7 стран. После дополнительной партии — 50 записей из 9 стран: Великобритания, Ирландия, США, Канада, Австралия, Новая Зеландия, ЮАР, Испания и Индия. Добавлены конкурсы романов, детских книг, отрывков, новые поэтические и прозаические конкурсы. Разные категории одного конкурса не равны разным организаторам.

Включены как международные конкурсы, так и конкурсы с ограничениями гражданства или проживания; последние вынесены отдельно. Охват не исчерпывающий: особенно требуется расширение по организаторам в Азии, Латинской Америке и континентальной Европе, а также по романам, драматургии и сценариям. Очередь исследования — `en/backlog.json`. Наличие записи в очереди не означает, что конкурс проверен или поиск выполняется автоматически.

Украинский каталог расширен с 17 до 20 записей: добавлены премия Нестайко от «Карітас Бердичів» и два конкурса Balabony. Организаторы находятся в Украине, США и международных организациях. Включены рукописи, опубликованные книги и международные категории INK-7. Необъявленные будущие сроки и неизвестные суммы оставлены пустыми; исторические призы помечены. Очередь дополнительных проверок — `uk/backlog.json`.

Поле `research_batches` хранит историю партий исследования и число добавленных записей. Список включает открытые конкурсы, будущие приёмы и закрытые сезоны. Общий размер каталога не означает число конкурсов, открытых прямо сейчас. Например, у Montreal двухлетний цикл; конфликтующие даты Caine Prize 2027 оставлены неподтверждёнными. Следующая возможная цель — 100 английских записей; очередь поиска не запускается автоматически.

## История событий

Значимые результаты записываются в корневой `history/events.json`. После его изменения запустить из корня репозитория:

```bash
python3 literary-competitions/scripts/render_history.py
python3 literary-competitions/scripts/render_history.py --check
```

Читаемые копии — корневой `CHANGELOG.md` и страница `docs/history.md`. Прошлые события восстановлены по фактическим коммитам GitHub; незавершённые проверки не выдаются за подтверждённые факты или успешную публикацию.
